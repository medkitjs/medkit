Only English ships. Every visible and spoken label can be replaced, in three places, checked
in this order:

| Where | How | For |
| --- | --- | --- |
| One element | `labels='{"play":"Pusti"}'` attribute, or `labels` passed to a renderer or component | A one-off |
| A language | `registerLocale('sr', { … })`, picked by the element's nearest `lang` | A site in another language |
| Everywhere | `configure({ labels: { … } })` | Rewording English |

A key left out falls back to the next place, then to English. `registerLocale('sr', …)` also
covers `sr-Latn` and `sr-Cyrl`. Elements read labels when they connect, so register before
the elements' modules run, or before you add elements to the page.

```js
import { registerLocale } from '@medkitjs/elements';

registerLocale('sr', { play: 'Pusti', pause: 'Pauziraj', next: 'Sledeći video' });
```

Placeholders such as `{current}` and `{total}` keep word order translatable:
`{current} od {total}` is as valid as `{current} of {total}`.
