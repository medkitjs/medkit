The package ships `custom-elements.json`, named in its `customElements` field and exported as `@medkitjs/elements/custom-elements.json`: every attribute, event, CSS part and CSS custom property of `<medkit-image>`, `<medkit-video-bg>` and `<medkit-player>`, for editor autocomplete and documentation tools.
